#4 · backend · effort medium

The local/LDAP login handler at server/auth.ts:780-838 has no per-IP or per-account throttle and no lockout; package.json contains no express-rate-limit or equivalent. Refuse an administrator demoting themselves or the last administrator

#25 · backend · effort low

PATCH /api/admin/users/:id/role (server/routes.ts:11891-11935) and PUT /api/admin/users/:id/secondary-roles (11792-11888) never compare :id with req.session.user.id and never count how many administrators would remain. Add an Origin/Referer check as a second CSRF layer beside SameSite=Lax

#47 · backend · effort low

CSRF protection currently rests entirely on the session cookie's sameSite: 'lax' (server/index.ts:117-121); there is no token and no Origin check, and package.json has no csurf/helmet.
